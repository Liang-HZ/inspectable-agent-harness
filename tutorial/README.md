# Agent Harness Tutorial

This directory contains two mirrored tutorials for the same project history.

- English: [tutorial/en/README.md](en/README.md)
- 中文: [tutorial/zh/README.md](zh/README.md)

The tutorial is intentionally separate from the other project docs:

- `docs/architecture.md` is the current system map.
- `docs/evolution.md` is the phase-by-phase change log.
- `tutorial/` is the teaching path: it explains why each layer appeared, what
  alternatives were discussed, what we deferred, and how the data flows through
  the code.
